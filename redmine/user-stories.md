## Story 列表（按 Epic 组织）

### EPIC-001：产品基础架构

---

#### STORY-001：前端项目脚手架搭建

**描述**：
作为前端开发人员，我需要搭建一个基于 React 18 + TypeScript + Vite 的前端项目脚手架，包括路由配置、状态管理、UI 框架集成、API 客户端封装，以便团队能够在此基础上高效开发页面。

**优先级**：Urgent  
**版本**：v1.0 MVP  
**负责人**：前端 Lead  
**预估工时**：16h

**验收标准**：
- [ ] `pnpm create vite` 创建项目，配置 TypeScript
- [ ] 集成 Ant Design 5，配置中文语言包和主题
- [ ] 集成 React Router v6，配置路由表
- [ ] 集成 Zustand + React Query
- [ ] 集成 ECharts 5
- [ ] 配置 ESLint + Prettier
- [ ] 配置路径别名（@/ → src/）
- [ ] 项目可 `pnpm dev` 正常启动

---

### EPIC-003：数据分析

---

#### STORY-026：指标计算引擎

**描述**：
作为数据分析师，我需要系统能够根据我选择的指标和维度，对数据集进行聚合计算，返回分析结果。

**优先级**：Urgent  
**版本**：v1.0 MVP  
**负责人**：后端  
**预估工时**：16h

**验收标准**：
- [ ] 支持 SUM、AVG、COUNT、MAX、MIN 聚合函数
- [ ] 支持按时间粒度聚合（时/日/周/月/季/年）
- [ ] 支持按维度分组（设备类型、区域等）
- [ ] SQL 查询使用参数化防注入
- [ ] 1000 条数据聚合 < 5 秒
- [ ] 返回数据包含指标摘要（均值、最大值、最小值、趋势方向）

**优先级**：Urgent

- [ ] 左侧配置面板（6 个步骤）
- [ ] 数据集下拉选择器（搜索+树形）
- [ ] 指标多选器（带聚合函数选择）
- [ ] 维度选择器
- [ ] 时间范围选择器（预设+自定义）
- [ ] 筛选条件构建器（字段+操作符+值，支持 AND/OR）
- [ ] 分析方式选择（趋势/对比/排名/异常）
- [ ] "开始分析"按钮
- [ ] 右侧结果区：图表 + 数据表 + 指标摘要 + 洞察

### EPIC-004：可视化看板

---

#### STORY-034：运营总览 Dashboard 页面

**描述**：
作为运营经理，我每天登录系统后首先看到运营总览页面，一屏了解核心 KPI、趋势、设备状态和待办事项，快速掌握运营全局。

**优先级**：Urgent  
**版本**：v1.0 MVP  
**负责人**：前端  
**预估工时**：16h

**验收标准**：
- [ ] 5 个核心 KPI 卡片（数据总量、今日新增、正常运行率、异常数量、设备利用率）
- [ ] 每个 KPI 卡片显示数值 + 环比趋势百分比 + 箭头
- [ ] KPI 之间数据存在业务逻辑联系（非独立随机数）
- [ ] 数据量趋势图（7 天折线图）
- [ ] 设备运行趋势图（7 天折线图）
- [ ] 设备状态分布（饼图或环形图）
- [ ] 待办列表（待处理预警、待巡检设备、数据源异常、数据质量异常）
- [ ] 切换时间范围（7天/30天/90天）
- [ ] 点击 KPI 卡片可跳转详情
- [ ] 点击待办项可跳转处理
